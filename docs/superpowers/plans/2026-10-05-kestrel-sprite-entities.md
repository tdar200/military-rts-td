# Kestrel Sprite Entities Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the Kestrel scenario, draw every building and unit as the mock boards' own painted sprite (upright cards on the 3D ground) instead of the blocky authored 3D models, so the live world matches gp01-gp08.

**Architecture:** Under `world_art_on` only, `_create_bridge_building` and `_create_unit` build a sprite visual (a `Sprite3D`-style upright quad, one per entity, textured with the mock's sprite PNG, drawn at the mock's pixel size converted to world units) instead of the `.glb` visual. The visual keeps the node contract the rest of the game relies on (`Visual` node for buildings, `UnitVisual` for units, `visual_tiles`, `pick_parts`, `crown_y`, `authored_scale`, health-bar offsets), so selection rings, picking, hover, construction growth, the era crown, labels and bars keep working. Survival keeps the legacy models and stays byte-identical.

**Tech Stack:** Godot 4.7.2 (Compatibility renderer, GDScript), the mock sprites in `assets/*.png` (256x256 RGBA, same files as `godot3d/assets/ui/sprites/` where present), `tools/ui/world_capture.py` / `world_diff.py` for scoring.

**Spec:** `docs/superpowers/specs/2026-10-05-kestrel-world-art-design.md` (addendum W6 said buildings and units stay 3D models; the user reversed that on 2026-10-05: "units and buildings dont look anything like the designs", chose "Billboard the painted sprites"). This plan overrides W6 for Kestrel.

## Review Focus

- A destroyed or still-under-construction building must not show a finished sprite (foundation sprite while building, gone when destroyed).
- Selection ring, health bar, badge, crown and relay label must sit on the sprite's real top/bottom, not the old 3D model heights.
- Picking: a click on the sprite's opaque pixels selects it; transparent corners of the 256x256 card must not steal clicks from a neighbour.
- Unit facing: a unit moving left shows the mirrored sprite; stationary units keep their last facing.
- Alien (enemy) sprites: use the `alien_*` sprites for the enemy faction; missing sprite kinds fall back to the existing model, never to nothing.
