Accessibility rules09
AColour plus shape plus word. Every state names itself and has its own silhouette.
BFaction by mark. Square brackets for friendly, diamonds for hostile, in any palette.
CScalable text. 13px floor at 1080p, UI scale to 150%, no key fact in a tiny icon alone.
DReduced motion. Scanline sweep and flicker switch off. Glow stays static.
EControls. Remappable bindings, adjustable warning timing, pauseable command planning.
