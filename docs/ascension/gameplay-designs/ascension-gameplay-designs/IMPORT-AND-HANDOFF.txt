03 Logistics: severed supply, ammo conservation, route recovery and depletion.

06 Core assault: optional relays, resupply, telegraphs, terminal outcomes and debrief.
07 Scale transition: tactical aggregation, planetary governors and ledger ownership.
08 Cosmic governance: sector autonomy, exotic-weapon counters and resilience victory.

IMPLEMENTATION BOUNDARY
These are proposed designs, not a report of existing or completed gameplay.
Costs, combat formulas, partial-consumption refunds, factory retrofits, rotation,
Core retaliation, simultaneous-destruction outcome and late strategic layers need
implementation and balancing. Current gameplay is described in ../IMPLEMENTED.md.
Existing game code has not been changed by this design task.
