# Gameplay mocks (Kestrel Reach), 12 boards

Source of the published canvas https://claude.ai/artifact/5CjjisvQHfZf8CatMDu8Am (private).
Boards are `.dc.html`; `hud.css` is shared. Sprites are referenced as `/_blob/<id>` (artifact assets); the shared world
image is `terrain/land.jpg` (3600x2400, generated by `terrain/gen.py` from the game's own textures and sprites).
Every board crops that world with a camera offset and places sprites in world coordinates.

Place names (Kestrel Reach, Calder River, Wyllow Ford, The Dry Flats, Ironback Ridge, Hollow Wood) and every number in
the boards are design proposals, not shipped behaviour.
