# Font licences

All three UI families are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows
bundling and embedding them in a game. Keep this file next to the font files.

| Family | Files | Source |
|---|---|---|
| Rajdhani (display) | `Rajdhani-SemiBold.ttf`, `Rajdhani-Bold.ttf` | Indian Type Foundry, via Google Fonts |
| IBM Plex Sans (body) | `IBMPlexSans-VF.ttf` (variable weight) | IBM Corp., https://github.com/IBM/plex |
| IBM Plex Mono (numbers, tags) | `IBMPlexMono-Regular.ttf`, `IBMPlexMono-Medium.ttf` | IBM Corp., https://github.com/IBM/plex |

`Cinzel-Bold.ttf` was already in the project before the UI work and is not used by `scripts/ui`.
